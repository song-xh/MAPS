# 06｜来源与修订记录

修订：2026-09-21。2026-09-20的源码与论文审查作为历史事实依据保留；本次按用户要求把实现范围收缩为两标签页demo，没有重新开展全量算法审计。

## 1. 本次设计修改

| 原方案 | 当前方案 |
|---|---|
| 五个工作区：Overview/Decision/Compare/Learning/Evidence | 两个标签页：过程演示/结果图表，算法细节在页内切换 |
| React/TypeScript + FastAPI | Python + Dash + Plotly + CSS，单个本地应用 |
| SQLite、Parquet、DuckDB与查询服务 | 简单本地JSON/CSV及当前结果内存 |
| Run Coordinator、任务调度、REST/SSE接口 | 直接函数调用；一次计算，完成后播放 |
| 通用事件流、快照恢复、任意分叉 | 预生成显示帧、索引播放、少量算法细节 |
| 运行、模型、实验、来源的管理能力 | 选择文件、加载、开始运行和简短来源说明 |
| 多seed/sweep/性能审计作为平台必需功能 | 留在原实验脚本；demo按需加载结果图 |
| 完整证据包、导出中心 | 可选保存图表/CSV |
| 8–10周平台建设路线 | 按加载→算法→回放→图表实现的轻量路线 |

明确取消登录、账号、权限、后台、多用户协作、在线训练与云部署。保留数据/模型兼容检查、真实指标、回放标识、正确算法语义，这些不需要额外页面或管理模块。

历史附件中的广泛建设建议不再是开发要求，当前范围以[需求](02-需求与验收.md)、[技术设计](03-技术架构与接口.md)、[界面](04-界面与交互设计.md)和[计划](05-实施与投稿计划.md)为准。

# MAPS Demo：交互式系统演示

当前实现设计见 [07 MAPS 系统演示设计](07-MAPS系统演示设计.md)。`01–06` 记录此前针对旧 CAPA 仓库的两标签页方案，保留作研究与界面参考；当前仓库的机制和验收以 `07` 与 `mpcs` 源码为准。

修订：2026-09-21。目标：VLDB / PVLDB Demonstrations Track 的交互演示。状态：设计文档，尚未实现。

## 当前方案

**一个本地 Dash 应用、两个标签页、少量按钮：加载数据 → 选择算法/加载模型 → 运行 → 动态回放 → 查看图表。**

- **过程演示**：地图、批次时间轴、包裹详情；在同一详情栏切换 CAMA、双层竞价和 RL 决策。
- **结果图表**：收益、准时完成率、处理时间、分配统计；可选加载已有算法对比和训练曲线。

使用 Python + Dash + Plotly + 少量 CSS，直接复用现有算法包。小场景计算后回放；大场景直接加载预计算结果。过程记录保存在本地 JSON/CSV 中，不建设数据库、独立前后端服务或实验管理平台。

不做登录、账号、权限、管理后台、模型管理、任务队列、多用户协作、在线训练、云部署和任意决策点分叉。算法/模型加载只支持项目已有方法和兼容的模型文件，不做通用插件系统。
